## 欠陥

- 凍結した辞書の国→言語の対応に、引用符なしのキー `NO: ["no"]` がある。PyYAML（YAML 1.1）の `safe_load` は
  引用符なしの `NO` を真偽値 false として読み、`topsem.world.lexicon.Lexicon` は `str(cc).upper()` で
  キーを `"FALSE"` にする。国コード `NO` の言語は空になり、ノルウェーの地名には辞書が一度も当たらなかった
- 辞書の全体を走査すると、文字列でないキー・値はこの 1 か所だけ（言語のブロック `no` そのものは正しく読まれている）
- 影響: 確証解析の主分割の標本のうち、最寄りの集落がノルウェーのセルは 33,813（11 AOI）。意図した対応なら
  そのうち 5,197 セル（15.4%、全セルの 0.34%）の最寄りの名前が辞書に一致する。辞書の特徴（と、その AOI 平均の
  地域構成）が全ての実行で 0 になっていた。浸水ラベルとの関係はこの確認では見ていない
- 発見の経緯: 初見の査読（blind 第 1 回、査読者 1）が公開リポジトリの辞書とコードを読んで指摘した。SI に
  「辞書に項目の無い言語の国はノルウェーだけ」と書いていたのは、この欠陥を辞書の欠落と読み違えたもの

## 修正

- `Lexicon` の YAML の読み込みを、YAML 1.2 と同じく `true` / `false` だけを真偽値とする読み方に変える
  （`yes` / `no` / `on` / `off` を文字列のまま読む）。凍結した辞書のファイルは変えない
- 全ての国のキーが 2 文字の文字列で、解析した国が意図した言語に対応することをテストする
