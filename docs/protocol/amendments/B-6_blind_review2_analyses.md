## 解析（番号は報告で使う）

### 1. 局所の効果の天井（解析的、既存の予測から）

主比較の推定量が、集落の近くだけの効果をどこまで拾えるかの上限。セルの集合 S の名前が完全に当たる（S のセルの予測が
ラベルに一致する）とき、主比較の分子が増えうる最大は ΔBS_max(S) = (1/N) Σ_{i∈S} (p_i − y_i)²（p は M1c の held-out
予測、N は全セル数）で、R_max(S) = ΔBS_max(S) / 物差し。S は (a) 最寄りの集落の名前が水系側で、集落から 500 m 以内の
セル、(b) 同じく 250 m 以内、(c) 1 km 以内、(d) 最寄りの名前が水系側の全セル。確証の実行（world_v2）と直した実行
（world_v2_lexfix）の両方で。**解釈の規則**: R_max(a) が余白 0.05 を下回れば「集落の近く（500 m）だけの効果は、どれほど
強くても確証の検定では meaningful と判定されえない」と書く。

### 2. 実データに効果を注入する模擬（plasmode）による上限の計算し直し

B-5 の 4 の検定の反転（合成ラベルの世界の 5 パーセンタイル）は、査読者 3 人と編集者が、実データの null（置換の分布）と
位置・広がりが合わないと指摘した。そこで実データのラベルに効果を注入し、二段目だけを当て直して増分を測る。

- **注入**: 主分割の各 fold で、基礎モデル（M0・M1）は確証と同じく 1 回だけ当て（B-5 の 1 と同じ仕組み、cross-fit の
  M1 の logit を固定）、対象のセルのうちラベルが 0 のセルを確率 q = (p′ − p)/(1 − p) で 1 にする。p はそのセルの M1 の
  予測（訓練側は cross-fit、評価側は held-out）、p′ = p e^δ / (1 − p + p e^δ)。訓練側と評価側の両方に注入する
  （名前に本当に効果がある世界）。文字の模型（N-learn）は注入後の訓練側のラベルで当て直す
- **対象の形**: (A) 最寄りの集落の名前が水系側（辞書の読み）の全セル、(B) そのうち集落から 500 m 以内、
  (C) 読み違いを入れた形: 集落ごとに潜在の「本当に水に関わる名」の印 L を引く。辞書が水系側と読んだ集落は確率
  π₁、それ以外は π₀ で L = 1（π₁ = v44 の水系側の層の真の割合、π₀ = 他の層の真の割合。どちらも重み無しの割合）。
  対象は L = 1 の集落に最も近いセル全体（C-A）と、そのうち 500 m 以内（C-B）。名前の特徴は辞書の読みのまま
- **格子**: δ ∈ {0.25, 0.5, 0.75, 1.0, 1.5, 2.0, 3.0}（オッズ比 1.28〜20）、各 δ・形で 10 回（乱数の種は形・δ・回から
  決める）。fold ごとに M1c と M3n の Brier を記録し、全 fold を合わせて ΔBS(δ) を出す
- **利得**: gain(δ) = 平均_回 ΔBS(δ) − ΔBS(0)（ΔBS(0) は注入しない同じ実行の増分 = 直した実行の確証の値）。回の間の
  標準誤差も
- **上限（主）**: 実データの null を基準にする。null の増分 ΔBS_null = B-5 の 1 の置換 200 回の ΔBS の平均。観測の増分の
  90% 区間の上限 U90（片側 95%）。δ_A = ΔBS_null + gain(δ) ≤ U90 を満たす最大の δ（格子の間は log オッズ比で線形補間。
  格子の端を超えれば「> 20」）。報告はオッズ比 e^δ_A
- **上限（副）**: (i) 基準を 0 にした δ_B（gain(δ) ≤ U90）、(ii) 95% 区間の上限 U95 で同じ計算
- **余白のオッズ比**: gain(δ) = 余白（0.05 × 物差し）となる δ_M（主比較の余白がどの大きさの効果に当たるか）。null の
  基準を足した δ_M′（ΔBS_null + gain(δ) = 余白）も
- **報告の規則**: 本文の上限と余白の翻訳は、この計算の値に置き換える（B-5 の 4 の値は付録に残し、合成の世界の広がりが
  実データの不確かさより小さいことを書く）。形 C の値を「辞書の区分」ではなく「本当に水に関わる名」の上限として書く。
  基礎モデルを固定したことによる近似（名前の効果は基礎モデルに入らない）を明記する。上限が格子を超える形は「この設計は
  その形の効果を上から抑えられない」と書く

### 3. 浸水の情報を持つ対照（設計がどこまで拾えるかの正の対照）

B-5 の 5 のオラクル（集落の地点の地形）は地形の情報しか持たず、名前が「地形の持たない浸水の情報」を持つ場合の上限には
ならない（査読者の指摘どおり）。そこで、浸水の情報を集落ごとに持たせた特徴を、名前と同じ割り当て（最寄りの集落から
セルへ）で入れ、M1c → M3n と同じ形の増分を主分割で計算する（地域構成の項 = その特徴の AOI 平均）。

- **(a) 事象のラベルの天井（漏れを承知の上限）**: 最寄りの集落の点から 500 m 以内の EMS で評価可能なセルの浸水の
  割合（その事象のラベル、セル自身を除く leave-one-out）。500 m 以内に評価可能なセルが無い集落は AOI の中央値。
  評価側の特徴も評価側のラベルから作るので予測としては漏れており、「名前が集落の周りのその事象の浸水を完全に
  知っていたら」の上限として書く
- **(b) 繰り返す水の記憶（漏れなし）**: JRC Global Surface Water v1.4（1984–2021、Pekel et al. 2016）の occurrence
  （水があった時間の割合、%）と seasonality（水のあった月の数）の、集落の点から 500 m 以内の 30 m 画素の平均。
  恒常水域（occurrence ≥ 90 かつ seasonality = 12）は除いた平均も。範囲読み出しで AOI ごとに取得する
- 比較は (a)・(b) それぞれ M1c 型の基準 → 特徴を足した模型。R と §6 の判定表の label
- **解釈の規則**: (a) の R が余白に届かなければ「この設計は、集落の周りの事象の浸水を完全に知る情報さえ余白に届く
  増分として拾えない」と書き、確証の null は集落の規模の主張について何も言えないと書く。届けば「設計は集落の規模の
  浸水の情報を拾える。名前の null は、名前がその情報をこの水準で持たないことを示す」と書く。(b) は「繰り返す水の情報」
  の増分として同じ形で書く
- **(c) 繰り返す水の正の対照（浸水のラベルを使わない）**: (b) の occurrence・seasonality（集落の点から 500 m 以内）を、
  B-2 の正の対照（集落の地点の HAND）と同じ形で、水系側の名の集落とそれ以外の集落の AOI 内の差（場所グループの
  クラスタ bootstrap 4,000 回）。辞書の区分別と、下の 5 の厳密な読みでも
