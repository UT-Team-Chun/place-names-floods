# English translations of the protocol and its amendments

The Japanese files (`../preregistration_v2.md` and `../amendments/`) are the record and govern where a translation differs.
The translations were drafted with a language model after the analysis and checked by the authors on 2026-11-06. Notes in
individual amendments written before that date (for example in B-11 and B-12) describe the state at the time they were
written.
