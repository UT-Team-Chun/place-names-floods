## 2. データ

### 2.1 観測浸水ラベル
- 出所: Copernicus EMS Rapid Mapping の delineation（DEL）製品。台帳は
  `scripts/ems_inventory.py` で作成し、2026-10-25 取得の版を `docs/data/ems_inventory_20261025.json`
  として固定（activation コード・AOI・製品 URL・版）。それ以後に公開された activation は
  使わない（時間外し評価の上限もこの時点）。日本の activation は台帳に無い（Study 1 と重ならない）。
- AOI あたり 1 製品: MONIT（監視）以外、広域（OVERVIEW/MAP/PRODUCT）優先、最新版
  （`topsem.world.ems.select_products`）。
- 格子: AOI 重心中心の LAEA、250 m セル。被覆率は 25 m 副格子（AOI が 25 万セル超なら 50 m）
  で計算（`build_aoi_labels`）。
- 評価可能セル: AOI 被覆 ≥ 0.5、観測域（撮像 footprint − Not Analysed）≥ 0.5、
  恒常水域（製品の参照水系多角形: hydrographyA / hydrography_poly / Hydrology_A_LAF）< 0.5。
- **主ラベル（riverine）**: y = 1 ⇔ obj_desc が Riverine の浸水多角形の被覆 ≥ 0.5。
  y = 0 ⇔ 種別を問わず浸水被覆 < 0.5。他種別でのみ浸水しているセルは主解析から除外。
- 種別の判定は**地物属性 obj_desc**による（activation の subCategory は使わない）。
  obj_desc が種別を明記しない製品（例: "Flooded area" のみ）の扱いは §2.4 の規則。
- floodDepthA など DEM 由来の層は使わない。

### 2.2 地名
- GeoNames 全件ダンプ（取得日・sha256 を記録）。主 = 地物クラス P（集落）。
  感度 = P+L+T+S。**H（水域名）は全解析で除外**。
- 文字列は `asciiname`。セルには最近傍 K=3 の P 名（距離つき）を割り当てる。

### 2.3 共変量（全て AWS Open Data・公開版を固定）
- 地形: Copernicus GLO-30 DSM、ASF GLO-30 HAND（v1/2021）。副格子へ双線形で再投影し
  250 m セルに集約（平均・最小・標準偏差・傾斜）。1 km 平均標高、相対低地度（paper_1 定義）。
- 水文: HydroRIVERS v1.0 — 全河道・上流面積 ≥ 1000 km² の主要河道までの距離。
- 土地被覆: ESA CCI Land Cover（1992–2015, v2.0.7cds）/ C3S Land Cover（2016–2020, v2.1.1）、
  300 m 年次。**各 AOI に洪水の前年の版**（2021 年以降の洪水は最新の 2020 年版）を当て、
  建物・農地・樹林・灌木・草地・裸地・湿地・水域の 8 群の被覆率にする（`topsem.world.landcover`、
  群の定義はコード内の CCI_GROUPS）。前年版なので洪水年の撮像は混入しない。地図化された湿地・
  水域も基準モデルに入れ、名前はそれを超える情報を持つかで試される。
  （草案の段階では ESA WorldCover 2021 を使う予定だったが、2012–2020 年の洪水には事後情報に
  なり、洪水で生じた裸地や流路変化がラベル情報を基準モデルへ漏らし得るので、凍結前に差し替えた）
- 集落幾何: 最近傍 P 名までの距離（log）、1 km・3 km 内の P 件数。
- 時点（`docs/data/point_in_time.md` の v2 節）: 土地被覆は全事例で洪水より前の版。河道
  （HydroSHEDS、2000 年 SRTM 由来）も全事例で前。地形（GLO-30 の撮像 2011–2015）は 2012–2015 年の
  洪水と重なり得るが、地形は事象でほぼ不変とみなす（§7-8 で 2015 年以前の事象を外す感度解析）。
  GeoNames は 2026 年のダンプで全事例の後だが、集落名は長く続くものとみなす（限界として報告）

### 2.4 採用基準（AOI 単位・凍結）
EMS 製品は 4 世代の書式がある（第 0 世代 2012–2013: `AreaOfInterest`・`Crisis_event_A`・
`Hydrology_A_LAF` / 第 1 世代 〜2017: `crisis_information_poly` / 第 2 世代: `observed_event_a` /
第 3 世代: `observedEventA`）。第 0・第 1 世代は種別の記載と撮像 footprint が無い。第 0 世代の
浸水は `Crisis_event_A` のうち SBTYPdes が Flood のもの（欄の無い製品は全多角形）とし、符号表が
公開されていない `intrp` は使わない。恒常水域は `Hydrology_A_LAF` のみ（`*_Optional_LAF` には島が
入る）。属性名の大文字小文字は区別しない。世代は meta.json の `schema_generation` に記録する。
**浸水を描画していない製品**（浸水層なし。ラベル済み 999 AOI 中 58）は全被覆 0 のラベルとして
台帳に残し、下の 1 で除外される（分母を残す）。
1. 評価可能セル ≥ 400、y=1 のセル ≥ 20、y=1 の割合 ≤ 0.8
2. AOI の浸水多角形のうち obj_desc が Riverine のものが面積比 ≥ 0.5。
   種別が未記載（第 0・第 1 世代など "other"）が面積比 ≥ 0.5 の製品は、**内陸**（AOI 重心が Natural Earth
   10 m 海岸線から 10 km 超）なら河川浸水とみなし、未記載の浸水も y=1 に数える。
   沿岸の未記載・Flash・Coastal は主解析から外し感度解析（§7-1）へ
3. AOI 格子の外接範囲内（余白なし）に P 名 ≥ 1
4. **場所グループ（§5）あたりの評価セルは合計 10,000 まで**。グループ内の AOI へ評価セル数に
   比例して配分し（最大剰余法）、各 AOI 内は固定シードで無作為抽出する（`group_quotas`）。
   主推定量はセルでプールするので、これで「場所」がほぼ等しい重みを持つ（未見の場所での予測という
   問いに対応）。草案の規則（単一 AOI が全セルの 2% を超えない最大の上限）は 2026-10-25 の発生表
   （採用 500 AOI・195 場所グループ）で 298,000（実質上限なし・1,492 万セル）となり、場所グループの
   実効数（Kish）が 195 中 35 に落ちるので、ラベル単独の比較（`backend/verification/r_okauchi/
   v32_cap_choice.py`、AOI 上限 1,000–298,000 とグループ上限 5,000–100,000）に基づき凍結前に
   差し替えた（グループ上限 10,000 で実効数 165・151 万セル）

## 4. 腕（特徴集合）と主比較の形

**主比較は入れ子の増分モデル**（既存のリスクスコアに新しいマーカーを足したときの増分価値と同じ形）。
基礎モデル（下の HistGB 腕）の予測を、学習側では内側 5 分割（場所グループ単位、N-learn と同じ分割）の
交差適合で、評価側では学習側全体で fit したモデルで作る。二段目は [基礎予測のロジット, 追加特徴] を
学習側の平均・標準偏差で標準化した L2 ロジスティック回帰（C = 1）（`world_eval.crossfit_base` /
`stage2`）。

**主比較は場所内の増分**: 基準側（M1c）に基礎予測と**名前の地域構成**（名前特徴 15 次元 — N-lex 14 と
N-learn 得点 — の AOI 平均、c_*）を入れ、名前あり（M3n）は基準 + 名前特徴そのもの。両者は同じ基礎予測と
同じ地域構成を共有するので、差は「名前が場所ごとに持つ情報」（危ない地名という主張の中身: この場所が
沼の名を持つ）になる。地域構成は「その地域にどんな名前が並ぶか」で、言語・地域を通じて地域ごとの浸水率を
拾い、置換 placebo でも同じだけ効く（凍結前の試走 pilot3、§8）ので、名前の意味の証拠にはならない。

- 主の腕: M1c / M3n（+ N-lex + N-learn）/ M3np（+ placebo）/ M3nx・M3nl（チャネル分解）/
  M1rc・M3rn・M3rnp（H4: 地域構成 = N-read 特徴の AOI 平均）/ M0c・M0n（H1）/ T0c–T3c・T0n–T3n
  （梯子 H3、最上段は M1c → M3n）
- 副 1（地域構成込みの全体の増分）: M1s（基礎予測の再較正だけ）→ M3s（+ 名前特徴）、placebo M3ps、
  H4 は M1s → M3rs / M3rps。名前が「データとして」予測を改善するかを示すが、言語・地域の代理を含む
- 副 2（柔軟モデル同士）: 以下の HistGB 腕を名前込みで学習し直す比較（M1 → M3 など）。凍結前の
  試走 pilot2 で、別々に学習した柔軟モデル同士の比較はモデルの揺らぎ（地形の増分の最大 29%）が名前の
  効果を覆うと分かったため副にした

基礎モデル・柔軟モデルの腕:

- M0: 位置（セル中心の緯度・経度）
- **M1**: M0 + 地形 T4（1 km 標高・平均標高・相対低地度・最小標高・標準偏差・傾斜・HAND 平均・
  HAND 最小）+ 水文（log 全河道距離・log 主要河道距離）+ 土地被覆 8 + 集落幾何 3
- **M3**: M1 + N-lex + N-learn
- M3p: M1 + placebo(N-lex) + placebo(N-learn)
- M3x / M3l: M1 + N-lex のみ / M1 + N-learn のみ（チャネル分解・副）
- M3r / M3rp: M1 + N-read / M1 + placebo(N-read)（H4）
- M0N: M0 + N-lex + N-learn（H1）
- 梯子（H3）: T0 = M0 + 水文 + 土地被覆 + 集落幾何、T1 = T0 + 1 km 標高、T2 = T1 + 平均標高 + 相対低地度、
  T3 = T2 + 最小標高・標準偏差・傾斜、T4 = T3 + HAND（= M1）。各段で ± (N-lex + N-learn)

学習器: `HistGradientBoostingClassifier(max_iter=200, learning_rate=0.1)`（v1 凍結値、他は既定）。
K = 5 シード（42–46）の予測確率平均。

## 5. 分割

- **主: 場所グループ外し**。各 AOI の外接範囲を 5 km 緩衝し、activation を跨いで交差する AOI を
  union-find で束ねた連結成分 = 場所グループ（異なるグループの AOI は 10 km 以上離れる）。
  グループを大陸 → セル数の順に並べ 10 fold へ巡回割当（決定的）。同じ町が別の洪水で再登場しても
  訓練と評価の両側には入らない。
- 副 1: 国外し（GeoNames cc の国単位で 10 fold、同じ規則で割当）— 未見言語への転移。
  国境をまたぐ場所グループは分けず、グループ内でセル数の多数派の国に寄せる
- 副 2: 時間外し — 評価 = 事象時刻 ≥ 2024-01-01 の AOI、訓練 = それより前の AOI のうち、
  **評価 AOI と同じ場所グループに属さないもの**（同じ場所の以前の洪水は両側から外す）。
- H4 分割（llmcut）: 副 2 と同じ規則で境界を 2025-02-01 とする（Gemma-4 の事前学習データ打切り
  2025-01・モデルカード記載の翌月初）。事後学習データの期間は公開されていないので、打切り後の
  情報が完全に無いとは言えない（限界として報告）
- bootstrap の単位: 主・時間外し・llmcut は場所グループ、国外しは国

## 6. 推定量・推論・判定

- 主推定量: 主分割のプール済みホールドアウト ΔBS(M1c → M3n) = BS(M1c) − BS(M3n)（正 = 名前で改善、
  §4 の場所内の増分）。
- 比 **R = ΔBS(M1c→M3n) / ΔBŜ(M0→M1)**（地名の場所内の増分が、位置に対する地形等の増分 — 柔軟モデルの
  M0 → M1 の点推定 — の何割か）。placebo・チャネル・H1・H4・梯子も同じ形で、分母は共通。
- **固定マージン法**: 判定は ΔBS の尺度で、余白を SESOI × ΔBŜ(M0→M1)（点推定）に固定して行う
  （非劣性試験の固定マージン法）。R の区間 = ΔBS の区間 / ΔBŜ(M0→M1)。地形の増分の bootstrap 変動係数は
  0.4–0.55 と大きく（pilot3）、比の bootstrap 区間は物差しの揺らぎで膨らむので、判定は名前の増分の
  不確かさだけで行う。比の bootstrap 区間は記述として併記する。
- 推論: 場所グループを単位とするクラスタ bootstrap（B = 4000、固定シード）。R は分子・分母を
  同じ再標本で計算。頑健性: activation × 国の二方向クラスタ bootstrap（v1 実装）。
- **SESOI: R = 0.05**。
- 区間はすべて percentile 法。
- 判定（H2、`world_aggregate.decide`。上から順に最初に当てはまるもの）:
  1. undefined-denominator: ΔBS(M0→M1) の 95% CI 下限 ≤ 0（R が定義できない。ΔBS で報告）
  2. not-meaning: R の 95% CI 下限 > 0 だが **R − R_p の 95% CI 下限 ≤ 0**（H2s 不成立。placebo が
     同等に効く改善は意味ではなく集落配置・置換不変の構造によるとみなす）
  3. positive-meaningful: R の 95% CI 下限 > 0、H2s 成立、R̂ ≥ 0.05（実務的に意味のある改善）
  4. positive-negligible: 同上で R̂ < 0.05 かつ R の 90% CI ⊂ (−0.05, +0.05)
     （0 より大きいが SESOI 未満と言える = 統計的には正、実務的には無視できる）
  5. positive-small: 同上で R̂ < 0.05、同等性は不成立（SESOI との大小は決着せず）
  6. negative: R の 95% CI 上限 < 0（名前を加えると悪化）
  7. **equivalent-null**: 上のいずれでもなく R の 90% CI ⊂ (−0.05, +0.05)（TOST、α = 0.05）
  8. inconclusive: それ以外（達成した上限を報告）
  TOST の成否は label と独立に併記する。
- **negative の解釈（凍結前、検出力の結果から）**: 名前効果の無い合成ラベル（δ = 0）では 100 回中 7 回が
  negative と判定された（推定した名前の重みが新しい場所へ移らず、予測をわずかに劣化させる）。negative は
  「名前が誤導する」証拠ではなく「移転できる情報が無い」ことを示すものとして読み、TOST の成否を併記する。
- H4: llmcut 分割で M1rc → M3rn を同じ判定表（placebo は M3rnp）で判定。
- 副: 全体の増分（M1s → M3s、placebo M3ps）と柔軟モデルの比較（M1 → M3、placebo M3p）にも同じ判定表を
  当てて並記する（主判定は変えない）。
- H3: 梯子の名前増分 Δ_k = ΔBS(T_k c → T_k n)（k = 0..4、T4 = M1）について、Δ_0 − Δ_4 > 0
  （片側、bootstrap）と、
  Spearman(k, Δ_k) < 0 を事前予測とする。T0 での「地形情報の回収率」
  ΔBS(T0c → T0n) / ΔBS(T0 → T4) を報告。
- H1: ΔBS(M0c → M0n) と R 類似量（分母 ΔBS(M0→M1)）。
- 多重性: 主は H2 のみ（H2s は主判定の必要条件）。H3・H4 は副で、それぞれ単独の α = 0.05、
  結果の解釈には Holm 補正後の値も併記。H5 は記述のみ。
- H5 の層（`world_aggregate.strata`・`by_continent`）: 最寄り名が辞書のいずれかの区分に一致するか
  否か、wetside か否か、セル内平均傾斜が評価セルの中央値以下（低起伏）か否か、CCI 建物群の被覆率
  > 10%（市街地）か否か、大陸。各層で ΔBS(M1c → M3n) と層内の ΔBS(M0 → M1) に対する比を記述する
  （1,000 セル・浸水 20 セル未満の層は出さない）。
- 副次評価量: 対数損失、PR-AUC、上位 10% 面積の浸水捕捉率（v1 と同定義）。

## 8. 検出力（凍結前に実施・合成ラベルのみ）

実データの特徴（地形・水文・土地被覆・名前割当）と発生表（AOI・グループ・セル数・浸水率）は
そのまま使い、**ラベルだけを合成**する: y* ~ Bernoulli(σ(α_AOI + f(地形・水文) + δ·g(N-lex)
+ 空間相関ノイズ))（`world_eval.synth_labels`。f の係数は事前に固定し、実ラベルからは推定しない）。
α_AOI は AOI の実浸水率に一致させる（実ラベルの唯一の使用で、AOI 単位の集計値）。δ は試走
（δ = 0.5・1・2、各 2 回）の R に R ≈ cδ² を当てはめて R = 0.05 となる値に決める。δ = 0 と
その δ で各 100 回（判定率が目標 ±0.05 以内なら凍結前に各 200 回へ増やす）、主解析の手順
（腕・分割・場所グループ上限・推論）を縮約版（K=1）で回し、
(a) δ=0 で TOST が決着した null を宣言できる確率、(b) R=0.05 で正の判定が出る確率、を推定する。
目標は (a) ≥ 0.8 かつ (b) ≥ 0.8。満たさない場合は**凍結前に** §2.4 の上限・SESOI を見直し、
理由を本文書に追記する。合成でも腕は M0・M1（柔軟、分母）と M1c・M3n・M3np（主）・M1s・M3s・M3ps
（副の全体の増分）を回し、判定は本解析と同じ `verdict`（固定マージン・placebo 条件込み）で行う
（bootstrap は 1000 回に縮約）。
偽陽性率（δ = 0 で positive の頻度）も報告する。

試走の記録（凍結前の設計変更の根拠）: 柔軟モデル同士の比較（M1 → M3）で δ = 0.5・1・2 を各 2 回
回した pilot2 では、ΔBS(M1→M3) が −1.2e-3〜+4e-4 と δ に依らず符号まで揺れ（ΔBS(M0→M1) ≈ 4e-3 の
約 25%）、placebo も同程度に揺れ、R の 90% CI 半幅は 0.18〜0.47 だった。SESOI（R = 0.05、ΔBS ≈ 2e-4）は
検出も同等性の宣言もできないので、主比較を §4 の入れ子の増分モデルに替えた。入れ子にした pilot3
（δ = 0・0.5・1・2、各 2 回）では、名前を足した改善 ΔBS(M1s→M3s) が δ = 0 でも +4.4〜6.0e-4 と正で、
置換 placebo でも同じだけ出た（地域構成が地域ごとの浸水率を拾う）。本物と placebo の差は δ に素直に
反応した（δ = 0 で ±1e-4、δ = 2 で +1.5〜3.2e-4）。また地形の増分の bootstrap 変動係数が 0.4–0.55 で、
比の区間を物差しの揺らぎが膨らませていた。そこで主比較を場所内の増分（地域構成を基準側へ）、判定を
固定マージン法にした。

δ の較正（pilot4、場所内の増分・固定マージン、δ = 0・1・2・3 各 2 回、上限 10,000）: R は
δ = 0 で −0.001・−0.003（90% CI 半幅 0.004–0.005、2 回とも equivalent-null）、δ = 1 で 0.039・0.027、
δ = 2 で 0.196・0.184、δ = 3 で 0.529・0.468。placebo の R は全条件で −0.006〜+0.001。δ = 1 と 2 の
間の log-log 当てはめ（R ∝ δ^2.53）で R = 0.05 となる δ は 1.18 → **δ = 1.2**（小数 1 桁に丸める）。
場所グループ上限 30,000 の試走（δ = 0・2 各 1 回）は区間を狭めなかった（90% CI 半幅 0.0045）ので
上限は 10,000 のまま。本計算は δ = 0 と δ = 1.2 で各 100 回（判定率が目標 ±0.05 以内なら 200 回へ）。

**本計算の結果**（run `power_v3_null`・`power_v3_sesoi`、各 100 回、K = 1、bootstrap 1000 回）:
δ = 0 で TOST の成立 99%（label: equivalent-null 91・negative 7・
inconclusive 1・not-meaning 1）、positive 0%、R の平均 -0.0008、90% CI 半幅の中央値
0.0035。δ = 1.2 で positive 98%（positive-meaningful 69・positive-small 29・
inconclusive 1・undefined-denominator 1）、R の平均 0.0567。目標（各 ≥ 0.8）を満たし、判定率は目標から
0.05 以上離れているので 200 回へは増やさない。
